# Cooker
Cooker is ai tools for job cooker

## BIST finans analiz API'si

Sunucuyu `npm run dev` ile başlat. Şirket verisi ve AI analiz endpoint'leri, örnek `curl` istekleri ve yanıt biçimleri için [BIST Finans API dokümantasyonuna](src/modules/fin_smell/API.md) bak.

Hızlı örnek:

```bash
curl -X GET http://localhost:3000/ai/fin-smell/THYAO/analyze
```
